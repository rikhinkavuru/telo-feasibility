\section{Run identifiers behind every table, and how to reproduce them}
\label{app:runs}

Every table in this memo is produced by a named run whose manifest is written to
\texttt{results/manifests/}. A manifest records the code version, the configuration digest,
the seed, the run count and the parameter overrides in force, so a table can be traced to
the exact state that produced it. All runs listed here postdate protocol revisions R009,
R010 and R011; every earlier run in the package is superseded for quantitative use and none
appears in this memo. Commands are run from the package root with the locked environment
(\texttt{make env}).

Two cautions belong with this table. The resolutions are not uniform: a verdict from the
threshold grid at 20 paired runs and a verdict from the verified feasible set at 100 are not
interchangeable, and where they disagree the memo reports both rather than choosing. And the
narrative documents in \texttt{docs/design\_space/} were written against the
\texttt{reeval\_post\_R009} artifact; the later optimization
\texttt{opt\_20260906T043357Z} and the batteries re-run on its designs are not yet
interpreted by any narrative document, which is why some figures in
Section~\ref{sec:limitations} differ from
\texttt{docs/design\_space/post\_R009\_correction.md}. That document remains the governing
statement of the verified feasible set, and it supersedes the earlier synthesis and the
regions document wherever they disagree.

Reproduction requires the frozen snapshots under \texttt{data/}, which are pinned by SHA-256
hash in the source register \texttt{config/sources.yaml} and verified by
\texttt{make protocol-hash}. Seeds are derived through \texttt{rng.RunStreams} from the run
index, a named stream, a BLAKE2b hash of the entity identifier and an ordinal, so a rerun at
the same run count reproduces the same world for every strategy. The complete assumption
register, generated from the configuration files rather than written by hand, is
\texttt{ASSUMPTIONS.md} in the package root, rebuilt by
\texttt{python scripts/build\_assumptions\_table.py}.
