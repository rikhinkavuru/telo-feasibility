# Limitations (living list)

1. Inputs: 55 product/global parameters plus 32 simulation placeholders are tier 5 (illustrative); only four release components carry a source. No result is a finding until they are replaced (ASSUMPTIONS.md).
2. Regulatory: 15 gates UNCERTAIN; no qualified review; decision maps are not legal advice.
3. Evidence: no interviews, reviews, quotes, or demand data; ASHP and two papers require human retrieval.
4. Model: one product per network; equal regional shares; single material policy; no substitution; provider harm not monetized; reserved capacity lacks a take-or-pay volume term.
5. Release assurance: public tablet spectra only; instrument is the only real group; lot/time groups synthetic; gate sensitivity depends on latent dimension (CV-selected vs fixed 8 components differ materially).
6. Backcasts: three ongoing shortages are "consistent" only because a chronic capacity gap never recovers; no documented single-site failure episode yet.
7. Verification: the adversarial second-pass over audit findings did not run (session limit); the anomaly registers carry one audit reading plus the main agent's direct reading.
8. Authorship: all code and prose in this package were produced with an AI coding agent; the author has not yet reviewed them (AI_ASSISTANCE.md).
