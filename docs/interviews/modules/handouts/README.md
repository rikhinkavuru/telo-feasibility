# Handouts: the only role material an interviewee ever receives

One page per role. Three columns and nothing else: the question, the units and entity level the answer should
be given in, and the answer form. **No model output appears in a handout**: no cost, fill rate, tail
probability, break-even price, ranking, frontier, threshold crossing or figure, and none of the modules'
"Lands on", "Now (declared range)" or "What it could reverse" columns.

Two reasons, and either is sufficient. The modules in `../` carry model results in three of their six columns,
and `../../outreach_templates.md` section K forbids putting any model output in an email; attaching a module
would have broken that rule in every template. And the "Now (declared range)" column is the study's own low,
base and high, which `../../elicitation_worksheet.md` section 3 says is shown only after the person's first
answer. Sending it ahead of the call destroys the anchoring rule the whole elicitation depends on.

The interviewer keeps the module. The interviewee gets the handout.
