# Sensitivity, structural uncertainty, and value of information

`sensitivity.py`. Inputs map to parameter records (`MANDATORY_INPUTS`, 19 of the protocol's 11.2 list) and vary only through their low/base/high. One-way sweeps report the preferred (min-cost feasible) strategy at each level and flag reversals. The decision-reversal map evaluates the preferred strategy over utilization (demand at fixed capacity), release critical path (sterility days), and common-cause rate. Global sensitivity uses Saltelli sampling with SALib Sobol first- and total-order indices on a paired response (annual cost of one strategy minus another, on common random numbers) and PRCC on the same sample. Value of information: triangular parameter sampling, EVPI = min_s E[C_s] - E[min_s C_s], EVPPI by cubic regression per parameter (Strong, Oakley and Brennan 2014); infeasible strategies carry a cap cost in a sample so they are never chosen when a feasible one exists. Sizes in `scripts/run_sensitivity.py` are modest by default and report sampling error.
