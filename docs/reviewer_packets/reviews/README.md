Completed reviews go here as `<review_id>.json` with fields: review_id, date, reviewer_qualification, packet, status (complete), compensated (whether the reviewer was compensated and how; "none" if not), relationship_disclosure (any relationship between the reviewer and any organisation named in the package; "none" if not), declined_sections (the parts of the packet the reviewer declined to review; "none" if not), issues (list of {issue, decision, rationale, affected_files, before, after}). The three provenance fields are a convention of these packets rather than a protocol requirement (`../README.md` section 6) and are recorded for honesty about provenance. None exist.
